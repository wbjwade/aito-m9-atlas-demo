## Modifications and attribution discrepancy

TeslaHub reports that its derivative was rigged for door/hood/trunk pivots, optimized with glTF-Transform and Draco, rescaled/reoriented, and had its materials remapped. The downloaded bytes have not been modified for this project. The application may recolor materials, reposition meshes and normalize the view at runtime for an illustrative structure browser; this is not engineering CAD.

TeslaHub's separate credit file identifies **ChoochooLi / Tesla Model 3 (Realistic Graphics)**, which conflicts with the GLB's embedded metadata. That upstream credit file is preserved without alteration as `UPSTREAM-CREDITS.md`. The original platform independently confirms the **aarajesh / Tesla White car.** identity embedded in the actual model. Both provenance records are retained here; neither attribution has been silently discarded. No TeslaHub application code was copied.

Attribution to display: **Tesla White car. — aarajesh, CC BY 4.0. Adapted model distributed by TeslaHub; view/material changes for Model 3 Atlas.** Keep this notice and the upstream credits when redistributing.

## Scope

This is a community visual model of a Tesla Model 3, not an official Tesla asset, and it has not been verified as Model 3 Highland. It is not a precise engineering assembly or repair reference. Battery and motor internals are not supplied or validated. Vehicle names and marks identify the depicted vehicle only; no affiliation or endorsement is implied.
