# AITO M9 Atlas

按用户参考图制作的本地 3D 汽车结构浏览器。React + Three.js + Vite；无需账户或后端。

## 使用

当前预览：http://127.0.0.1:4174/

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4174
```

需要 Node.js 20.19+ 或 22.12+。构建：`npm run build`；检查：`npm test`。生产静态文件在 `dist/client`。必须通过 HTTP 服务打开，不能双击 HTML 使用 `file://` 加载模型。

## 已实现

- 用户提供的真实问界 M9 GLB 模型，54 个可选模型部件、8 个可视化分类。
- 拖动旋转、滚轮缩放、前/侧/俯视、按钮及键盘替代操作。
- 系统筛选、分组显隐、部件列表、画布点选与高亮。
- 0–100% 结构展开，视野自动调整，一键恢复。
- 加载、错误重试、全隐藏恢复、帮助对话框和手机宽度适配。
- 模型及贴图本地提供，无运行时 CDN，也无需 Draco 解码器。用户动作仅存在当前页面，不收集或上传。

## 模型与限制

使用用户提供的 `aito-m9.zip`，作者 **MattDoesBlender**，许可 **CC BY-NC-SA 4.0**（署名、非商业、相同方式共享）。见 [原始许可](public/models/aito-m9/license.txt) 和 [模型检查记录](docs/m9-model-inspection.md)。保留原始 glTF、二进制和贴图；`scripts/pack-m9.mjs` 将资源封装为自包含 GLB，不修改原始几何数据。

运行时调整车漆、玻璃、金属材质和显示尺度。原模型只有一个轮胎/轮毂模板，程序复制成四组并按轮拱作展示性装配；无定位数据的车牌模板不参与显示。54 个部件对应 235 个渲染网格实例，既不是原文件的 230 个网格数，也不是实车零件清单。部件按原始命名总成分组，展开时保持各总成内部材质网格相对位置。

不是华为/问界官方工程图谱，没有独立电池、电机或悬架结构。轮组位置与展开仅为空间示意，不能作为维修或尺寸依据。资产仅限非商业用途；分享模型或修改版本时须保留署名与原许可要求。

目前交付电脑浏览器版，未生成手机 APK/HAP，未发布到外网，也未修改「轻记」项目。

## 项目入口

- `src/App.jsx`：界面及状态
- `src/viewer.js`：3D 场景、模型、相机及点选
- `src/m9-parts.js`：M9 配置、分类及中文部件名
- `src/build-m9.js`：总成提取、轮组装配与材质调整
- `src/model-state.js`：通用状态工具及保留的旧模型分类
- `src/styles.css` / `DESIGN.md`：视觉样式及设计约束
- `tests`：状态/模型资源与静态服务测试
- `docs/reference.png`：用户提供的参考截图

依赖许可证见 `public/THIRD-PARTY.md`。旧 Tesla 资源及许可作为历史资料保留，但不再加载。当前未部署到外网。
